# Farming Video Assets

These video clips are free, no-attribution stock footage curated for Digital Krishi Officer background views and previews.

| File | Resolution | Theme | Size |
|---|---|---|---|
| `wheat-field.mp4` | 720p HD MP4 | Golden wheat field swaying gently in the wind | ~6.85 MB |
| `tractor-farming.mp4` | 720p HD MP4 | Modern tractor / harvester mowing through field | ~4.91 MB |
| `paddy-field.mp4` | 720p HD MP4 | Lush green tiered paddy fields aerial view | ~5.64 MB |

### Re-downloading Videos
To download or update these video files on a fresh clone:
```bash
npm run download:videos
```
